# PCB·HFSS 검증: 보드 배선에서 실제 측정 경로까지

[파트 개요](../README.md) · [LPDDR](lpddr.md) · [USB PAM-3](usb4-pam3.md) · [측정 장비](measurement-equipment.md) · [논문·근거](evidence.md)

**칩의 출력 파형을 해석하려면 PCB와 연결부가 신호에 주는 영향도 확인해야 했습니다.** 측정용 PCB의 회로·배치·배선 설계, HFSS의 전달 특성 검토와 COB 실장·계측 환경을 사진과 해석 그림으로 연결했습니다. 설계 화면에서는 무엇을 확인했는지, 해석 곡선에서는 어떤 판단까지 가능한지 설명합니다.

개인 PCB 설계·HFSS 분석 범위와 아래 LPDDR 사례의 그림은 `윤주형_연구 포트폴리오.pptx` slide 6에 근거합니다. USB 보드 사례는 별도의 공동 작업 자료로 표시합니다. **HFSS 결과는 전자기 해석이며, 보드 사진이나 장비 연결 사진 자체를 신호 성능의 측정값으로 사용하지 않습니다.**

## 1. 제작 보드와 설계 화면에서 같은 신호 경로 확인

측정용 보드에는 고속 데이터·클록 경로와 전원·제어 연결이 함께 들어갑니다. 칩 주변 배선만 따로 보기보다 커넥터에서 칩까지의 경로와 계측에 필요한 연결을 함께 확인했습니다. 아래 설계 화면과 제작 사진은 중앙의 칩 실장부에서 바깥쪽 커넥터로 이어지는 배선을 보여줍니다.

## 2. HFSS에는 분석할 배선과 기준 조건을 함께 반영

보드 전체 화면만으로는 어떤 경로의 손실을 계산했는지 알기 어렵습니다. HFSS에서는 **칩 쪽 패드와 커넥터 쪽 연결 사이의 분석 구간**을 확인하고, 그 구간의 포트·기준 접지·적층 정보를 해석 조건과 연결했습니다. 아래 그림은 칩 쪽에서 여러 커넥터 방향으로 나뉘는 배선과 주변 접지·via가 포함된 해석 구간입니다.

연구실의 HFSS 작업 자료는 PADS의 배선을 ODB++로 옮긴 뒤 적층·재료·두께를 확인하고 포트를 설정하는 절차를 설명합니다. Import 직후에는 재료·두께 정보나 포트가 빠져 validation 문제가 발생한 기록도 있습니다. 형상이 화면에 나타나는 것과 해석 조건이 완성되는 것을 별도로 확인한 이유입니다.

| 확인 대상 | 해석 전에 확인한 내용 | 판단에 필요한 이유 |
|---|---|---|
| 분석 구간 | 칩 쪽 패드·커넥터 쪽 연결과 포함된 배선 | 손실 수치가 어느 구간에 해당하는지 정하기 위해 |
| 적층·재료 | 도체·유전체의 층과 두께, 재료 정보 | 형상만 가져온 불완전한 모델로 결과를 해석하지 않기 위해 |
| 포트·기준 접지 | 신호와 접지의 위치, 포트 구성 | 포트 설정 문제와 실제 배선의 전달 특성을 구분하기 위해 |
| 모델·경계 | 보드 외곽과 유전체 범위, 커넥터 접촉 형상 | 겹침·연결 누락 등 모델 문제를 먼저 확인하기 위해 |

**절차 참고:** `PAD_IMPORT_정리.pptx` slides 9–14, `HFSS_Modeling_Analysis_정리 1.pptx` slides 12–17, `SMA_연결_보충.pptx` slides 6–12. 이 자료들은 연구실 공통 작업 기록입니다. 그 안의 모사채널·SMA 모델 결과를 개인 LPDDR 보드의 결과로 합치지 않았습니다.

## 3. 한 주파수의 손실과 대역 중간의 notch를 함께 검토

대표 주파수의 손실만 작아도 다른 대역에서 전달 특성이 급격히 변하면 추가 검토가 필요합니다. HFSS의 여러 전달 경로를 함께 보며, 완만하게 증가하는 손실과 일부 경로에서 나타나는 좁은 대역의 dip·notch를 구분했습니다. 포트폴리오에는 **배치·배선 수정 전후의 채널 특성을 비교한 활동**이 기록되어 있습니다.

| 일부 경로에 notch가 나타난 해석 결과 | 6.4 GHz 지점에 값이 표시된 해석 결과 |
|---|---|
| ![여러 전달 경로 중 일부에서 좁은 대역의 notch가 보이는 HFSS S-parameter 곡선](../assets/pcb_hfss_lpddr_sparams_notch.jpg) | ![6.4GHz에서 여섯 전달 경로의 값이 표시된 HFSS S-parameter 곡선](../assets/pcb_hfss_lpddr_sparams_6p4ghz.jpg) |

**출처·판독:** 같은 포트폴리오 slide 6. 왼쪽 모델명은 `PCB_cutout1`, 오른쪽은 `PCB_cutout6`입니다. 오른쪽 6.4-GHz 마커에는 여섯 전달 경로의 값이 **약 −1.58~−2.14 dB**로 표시되어 있습니다. 이는 HFSS의 전달 S-parameter이며, VNA 실측값이나 전체 케이블·계측 경로의 손실이 아닙니다.

두 그림은 검토한 모델의 결과를 보여주지만, 슬라이드에는 변경한 배선 위치와 두 모델의 전체 포트·적층·경계조건이 함께 제시되어 있지 않습니다. 따라서 **특정 수정만으로 notch를 제거했다는 단정이나 개선율 계산은 하지 않습니다.** 곡선의 세로축 범위도 달라 화면상 높이 대신 주파수와 dB 축을 읽어 비교합니다.

## 4. USB 보드에서는 신호 경로와 전원 공급 경로를 함께 검토

USB TX의 공동 PCB 자료에는 GND via의 배치 간격을 검토하면서 전원층의 공급 경로가 끊기지 않도록 조정한 내용이 있습니다. 자료는 균일한 GND via 배치를 사용한 구조에서 일부 via를 제거한 구조와 비슷한 손실을 확인했다고 설명합니다. 이에 맞춰 VDDQ 공급 위치와 VBIAS 연결을 정리하고, SMA 커넥터 주변의 공간도 확보했습니다.

| USB CLK 경로 | USB DATA 경로 |
|---|---|
| ![USB TX PCB의 CLK 전달 경로 S-parameter 곡선](../assets/pcb_hfss_usb_clock_sparams.png) | ![USB TX PCB의 DATA 전달 경로 S-parameter 곡선](../assets/pcb_hfss_usb_data_sparams.png) |

**출처·조건:** 같은 자료 slide 3. 슬라이드는 12.8 GHz에서 CLK 경로의 손실을 **약 1.11 dB**, DATA 경로를 **약 1.25 dB**로 기록합니다. 양수는 손실량의 크기이며, 원본 곡선의 전달 S-parameter는 음수 dB로 표시됩니다. 두 CLK 곡선의 커서값은 −1.12/−1.11 dB, DATA는 −1.25/−1.26 dB입니다. PCB 해석 결과이며 제작 TX의 Eye·BER 실측과는 별도로 읽습니다. 이 공동 작업 자료만으로 각 배선 변경의 단독 수행자를 추가 지정하지 않습니다.

## 5. 실제 장비 연결에서 회로·보드·계측의 역할 구분

보드를 제작한 뒤에는 신호 공급, 칩 설정·전원과 출력 관측 경로가 실제로 연결돼야 합니다. 아래 사진에서는 PPG·BERT, 전원공급기, 오실로스코프와 TX 보드의 위치를 확인할 수 있습니다. HFSS로 검토한 보드 경로와 계측에 사용하는 케이블·연결부를 구분해, 어느 구간을 해석했고 어느 구간에서 파형을 관찰했는지 설명하는 근거입니다.

<summary>실제 측정 환경 사진 보기</summary>

![PPG와 BERT, 전원공급기, DCA-X 오실로스코프 및 TX 보드가 표시된 측정 환경](../assets/pcb_hfss_measurement_setup.jpg)

**출처·사진의 표기:** `윤주형_연구 포트폴리오.pptx`, slide 6. PPG·BERT 모듈은 Anritsu MU183020·MU183040, 전원공급기는 RIGOL DP832·Keysight E3631A, 오실로스코프는 Keysight DCA-X 86100D로 표시되어 있습니다. 사진은 장비 배치의 근거이며, 이 한 장으로 모든 장비의 동시 동작이나 특정 BER 관측 조건을 증명하지는 않습니다.

</details>

장비별 역할과 입력 주파수·오류 판정 조건을 맞춘 사례는 [측정 장비와 활용](measurement-equipment.md)에 있습니다. LPDDR의 TX Eye·RX Shmoo와 USB의 FFE 적용 전후 Eye는 [검증 그림](verification-figures.md)에서 각각의 측정 조건으로 확인할 수 있습니다. **그 Eye 수치를 PCB 수정에 따른 직접적인 개선량으로 사용하지 않습니다.**

기존 연구자료의 설명을 보강한 페이지입니다. 이번 정리에서 PCB 파일 수정·보드 제작·HFSS 해석·VNA 측정·칩 측정을 새로 실행하지 않았습니다. 공개한 자료는 선별 이미지와 설명이며, PCB/Gerber 원본·HFSS 프로젝트·원본 발표자료는 포함하지 않았습니다.
